# Task Board

A vanilla JavaScript task management app — no frameworks, no libraries. Tasks are persisted in the browser via localStorage so they survive page refreshes.

## Features

- Add tasks with a description, date, and time
- Validates that the selected date/time is in the future
- Tasks display in a scrollable board, newest highlighted at the bottom
- Delete any task with a single click
- Data persists across sessions using localStorage

## Tech Stack

- JavaScript (vanilla)
- HTML / CSS
- localStorage

## Getting Started

No build step required.

1. Clone the repo
2. Open `index.html` with Live Server (VS Code extension) or any static file server
